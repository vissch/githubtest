# Trench Warfare 3D

Roadmap and Unity 6 project for rebuilding *Trench Warfare 1917* (2D lane RTS) as a 3D tactical title with a
deterministic lockstep simulation. Ship target: **Windows x64**.

## Working on the Unity project

Requirements: **Unity 6000.0.50f1** (Hub install, Windows Standalone module) and the
[Unity CLI](https://docs.unity.com/cli) (`unity --version`; install per the `unity-cli` skill if missing).

```powershell
cd trench-warfare-3d

# Fresh clone: URP asset, Active Input Handling = Input System, Bootstrap + GreyboxCorridor scenes
unity run . -- -nographics -executeMethod TW.Editor.BootstrapSceneBuilder.SetupAll

# The gate before every commit (exit 8 = a test failed; exit 6 = no verdict, e.g. compile error)
python validate.py
unity test . --mode EditMode --timeout 600
unity test . --mode PlayMode --timeout 600 -- -nographics

# Optional: let agents drive the open editor (adds com.unity.pipeline)
unity pipeline install
```

In the editor the same steps are menu items: **TW → Setup Project**, **TW → Setup Input Handling**, **TW → Build
Bootstrap Scenes**, then **Window → General → Test Runner**. Press Play in `GreyboxCorridor`: capsule units flow
along the corridor under the debug overlay.

`validate.py` checks JSON, the assembly graph, sim purity and phase headers **without Unity**; it does not compile
C#. `unity test` is the real gate.

## Working in phases
Every assembly under `Assets/_Project` maps to a phase in [01 Phases and dependencies](docs/01-phases-and-dependencies.md).
Stub files carry a `// Phase: <id>` header naming the phase that implements them and the contracts they depend on.
The assembly definition references enforce the dependency direction (`Sim` never references `Presentation`, `UI`, `Net` or `Data`).
Every new sim system ships with a determinism replay test (see the checklist in [03](docs/03-determinism-rules.md)).

Packages: add or remove them with the `unity-package-management` skill's `Client` API script, not by editing
`Packages/manifest.json`; commit `packages-lock.json` alongside it.
