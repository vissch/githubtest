# Trench Warfare 3D

A rebuild of *Trench Warfare 1917* (a 2D lane RTS) as a 3D tactical game on a deterministic lockstep simulation.
Unity 6000.0.50f1, Windows x64 only.

**Working on it, human or agent: start with [`CLAUDE.md`](CLAUDE.md).** It gives the three files to read, the lane
you are in, the land checks and the gate.

## Layout
| Path | What |
|---|---|
| `trench-warfare-3d/` | The Unity project: 19 assemblies under `Assets/_Project/`, tests, `Tools/` scripts. Map: `docs/reference/code-map.md` |
| `docs/reference/` | The pages you work from: where things are, how to run and test, decisions, flags, pipelines |
| `docs/` | Design documents 00-20 and the original plan; index in [`docs/README.md`](docs/README.md) |
| `gate.ps1` | The pre-commit gate: `validate.py`, EditMode, PlayMode |
| `.github/workflows/unity.yml` | CI generated by `unity ci init`: tests and a Linux player build. It needs repository secrets and has not run green; the shipping target is Windows |
| `github-test1/` | An unrelated older Unity test project. Not part of the game |

## Quick start
```powershell
cd trench-warfare-3d
unity run . -- -nographics -executeMethod TW.Editor.BootstrapSceneBuilder.SetupAll   # fresh clone only
python Tools/health.py                                                                  # is this checkout sane?
Tools/tw up                                                                             # open an editor for it (Git Bash)
```
Open `Assets/_Project/Scenes/GreyboxCorridor.unity` and press Play. The HUD's bottom bar deploys units and each of
your trenches has order buttons. F9 switches between the UI Toolkit HUD and the older IMGUI one.
`docs/reference/workflow.md` covers tests, captures and builds.
