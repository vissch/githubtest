# Docs index

`CLAUDE.md` at the repo root is the entry point, and `docs/reference/` holds the pages an agent works from. This
page indexes the design documents: why each system is built the way it is. Open one when a task changes a system's
design, not to find a file (`reference/tasks.md` does that).

## Status (2026-09-25)
- **M1 greybox corridor:** done. 2,000 units hash-identical over lossy loopback.
- **M1.5 fun gate:** code complete. The two-developer playtest has not happened (`reference/decisions.md`, Open).
- **M2 look, in progress on the owner's word:** VAT infantry with baked Mixamo figures and a 105-clip atlas; the
  per-man animation ladder; generated battlefield with river, woods, wire, craters and night weather; tanks and
  six crab walkers; destruction of props, houses and ground; UI Toolkit HUD, selection and menus; coast and snow
  levels; a performance pass that made single player one sim world.
- **Not started:** audio (no assets), the mission runner and wave AI (stubs), online transport (after Mission 3).
