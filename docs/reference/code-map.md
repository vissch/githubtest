# Code map

Open this when a task adds an assembly, a folder or a sim system, or when `tasks.md` has no row for what you are
looking for. For "which file do I change", `tasks.md` is faster. The tables are generated by `Tools/codemap.py` from
the asmdefs, the folders and `Sim/Match/MatchSim.cs`; edit the code or the script, never the tables.

## Things the folder names will not tell you
- **Assembly names are not namespaces.** `TW.Sim.Core` declares `namespace TW.Sim`; `TW.Presentation.Core` declares
  `TW.Presentation`; `TW.Presentation.Camera` declares `TW.Presentation.Tactical`. A `using` takes the namespace.
- **`Presentation/Camera/` is mostly not camera code.** It holds CombatFx, TankRenderer, WalkerGait, Flamethrower,
  DebrisRenderer, FlipbookFx, the IMGUI BattleHud and TestPanel, because they need `TacticalCamera` and nothing
  else was allowed to reference it when they were written.
- **A class can live in a file with another name.** `TrenchGarrisonSystem` is in `Sim/Units/TrenchGarrison.cs`,
  and `SceneHooks`, `SceneTints`, `SceneMood`, `FrameBudget` in `Presentation/Core/RenderGround.cs`. Search for the class declaration, not for a file named after it.
- **Two partial classes:** `PropDestruction` across `Presentation/Terrain/PropDestruction.cs` and `PropWear.cs`;
  `CombatFx` across `Presentation/Camera/CombatFx.cs` and its `.Ground`, `.Chunks`, `.Ambient`, `.Bodies` parts.
- **`Presentation/VFX/` and `Presentation/Audio/` are stubs.** Effects are in `Presentation/Camera/`; there is no audio.

| Sim → presentation: events and interpolated poses | `Presentation/Core/EventPump.cs`, `Presentation/Core/SimPresenter.cs` |

| Fresh-clone setup | `Editor/BootstrapSceneBuilder.cs`, `SetupAll` |
| Stills, benches, captures | `Editor/CaptureRig.cs`, `Editor/TankCapture.cs`, `Editor/UI/HudCapture.cs` |

## Shaders
All TW shaders are in `Shaders/`. A shader loaded with `Shader.Find("TW/...")` must be in Always Included Shaders or
referenced by a material in `Resources/ShaderKeep/`, or it is missing from the player build. ShaderInclusionTests
enforces it. Shared includes: `TWAtmosphere.hlsl` (fog, haze), `TWLocalLights.hlsl` (night lights), `TWWater.hlsl`.
Instanced-indirect shaders index instance data with `GetIndirectInstanceID_Base`.
